仓库体检

扫一遍 jobs/：空目录、重复 code 的作业集、版本目录名不是日期、目录名与作业集名称不一致。

① 上传作业集

拖入编辑器导出的 .json（也认 .txt），或直接拖入 上架包_*.bundle.json，会自动读取里面的作业集。
同一阵型下，作业集名和已有的一致 = 迭代新版本（旧版本原样保留）；写成新名字 = 新建一份作业集；不同阵型允许同名。
写入时会自动规整：局外选卡强制「自动选卡」，候选池只留本作业集实际用到的植物。
把作业集或上架包拖到这里
或者点这里选择文件
写入后索引会自动重建，刷新「首页预览」即可看到

② 现有作业集（改作者 / 说明 / 名字 / 版本）

作者和说明就写在每个版本目录的 作者.txt / 说明.txt 里，改完记得 commit + push。

③ 维护操作

站点是纯静态的：这里的改动只落在本机仓库里。上线要 git add -A; git commit -m "…"; git push 或交给 GitHub Desktop；推送后 1~2 分钟 Pages 自动部署。
