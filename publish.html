① 拖入作业集文件

支持编辑器导出的 .json（也认 .txt）；可以一次拖多份，也可以选整个文件夹批量导入。
把作业集文件拖到这里
或者点这里选择文件 / 选整个文件夹

② 选择导入方式

每份文件二选一：迭代作业集（同一套方案出新版本，旧版本自动保留）或 新建作业集（新建一份方案）。

③ 生成上架包

上架包是一个 .bundle.json 文件，里面装着作业集原文 + 你的选择（阵型 / 版本 / 作者）。传到仓库 inbox/ 后，GitHub Actions 会自动落库并刷新站点索引。
下载上架包
  1. 下载上架包（.bundle.json）。
  2. 在 GitHub 网页打开仓库的 inbox/ 文件夹 → Add file → Upload files → 选这个上架包 → Commit changes。
  3. 等 1~2 分钟，Actions 会自动把作业集落进 jobs/<阵型>/<作业集>/<版本日期>/（不归入阵型就省掉阵型那层） 并重建索引，刷新首页就能看到。
没有 GitHub 权限的维护者：把上架包发给仓库管理员即可。
本地有仓库的人：python -X utf8 tools/apply_inbox.py 你的上架包.bundle.json → git push。

仓库目录长这样

jobs/
  心塔/                                  ← 阵型（可省略）：同类型作业集放一起
    失落原大火龙果/                        ← 作业集（新建一次 = 一个目录）
      2026-10-19/                        ← 版本目录（建议用创建日期）
        失落原大火龙果.json                ← 作业集本体
        作者.txt                          ← 作者名（一行）
        说明.txt                          ← 可选：这一版改了什么
      2026-10-25/                        ← 再迭代一次 = 多一个日期目录
        失落原大火龙果.json
        作者.txt
        说明.txt
站点不读任何手写清单：目录树就是数据源，索引由脚本自动生成。
