上传作业集

把编辑器导出的作业集 JSON 文件拖进来，站点会本地解析并校验； 然后给里面每棵植物标注要不要装扮（必填），最后一键打开 GitHub 投稿页—— 正文已经预填好，你只需把刚才那份 .json 文件拖进投稿页的「作业集 JSON」一节 （GitHub 会自动上传成附件），机器人会下载附件校验并自动开 PR，维护者审核合并后即可上站。

🌱
把 .json 文件拖到这里，或点击选择文件
只在你的浏览器里本地解析，不会上传到任何地方

需要装扮的点「需要」（会标黄），其余点「不需要」。标注结果会写进投稿，决定详情页的「需装扮」徽标和主页筛选。

去投稿

两种方式任选其一。内容不大时推荐方式一，一键搞定。

方式一（推荐）：一键投稿

打开 GitHub 投稿（已预填）

方式二：备用

正文里不含 JSON 本体——打开投稿页后，把刚才那份 .json 文件拖进「作业集 JSON」那一节（GitHub 会自动上传成附件链接），再提交。
