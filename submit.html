上传作业集

把编辑器导出的作业集 JSON 文件拖进来，站点会本地解析并校验； 然后给每棵植物标注装扮、选好适用世界，点「生成投稿」→「复制正文并打开投稿页」， 在打开的 GitHub 页面里 Ctrl+V 粘贴提交即可。机器人会自动校验并开 PR，维护者审核合并后即可上站。

🌱
把 .json 文件拖到这里，或点击选择文件
只在你的浏览器里本地解析，不会上传到任何地方

需要装扮的点「需要」（会标黄），其余点「不需要」。标注结果会写进投稿，决定详情页的「需装扮」徽标和主页筛选。

会显示在站点卡片和详情页上，也是主页世界筛选的依据。
